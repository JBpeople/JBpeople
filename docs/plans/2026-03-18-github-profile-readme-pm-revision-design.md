# GitHub Profile README Revision for JBpeople

## Overview

This revision reshapes the profile README from a blog-style personal homepage into a more professional profile for a product manager. The target impression is concise, credible, and useful as a supporting signal for job opportunities, without explicitly mentioning job seeking.

## Positioning

- Role focus: Product Manager
- Domain emphasis: To B products
- Strength cues: process design, requirements management, cross-team collaboration, delivery follow-through
- Tone: restrained, professional, and readable

## Revision Goals

- Reduce personal or emotional wording that feels overly expressive.
- Make the page easier to scan in under one minute.
- Shift the center of gravity from "personal story" to "professional orientation".
- Keep the page appropriate for GitHub while still relevant to a product role.

## Content Strategy

### 1. Header

- Keep only the name, role direction, and one short positioning sentence.
- Remove welcome-style language.

### 2. Focus Areas

- Use short bullets to show the product directions that matter most.
- Prioritize To B product work, process design, and requirements management.

### 3. Working Style

- Show how work is approached instead of writing broad self-description.
- Highlight problem definition, process clarity, documentation, and delivery closure.

### 4. Projects and Outputs

- Reserve a section for future project links or document examples.
- Avoid fake or inflated claims when detailed cases are not yet provided.

### 5. GitHub Snapshot

- Keep only light supporting visuals.
- Remove language-heavy developer signals that are less relevant for a product manager profile.

## Removals

- Long first-person introduction paragraphs.
- Lifestyle or hobby-like wording such as "折腾" and "成长" style copy.
- Large technical badge wall.
- Overly sentimental closing language.

## Assumptions

- The user prefers not to mention job-seeking explicitly.
- The page should support professional image rather than personal branding.
- Specific project cases and external links can be added in a later refinement pass.

## Implementation Notes

- Update `README.md` in the `JBpeople` repository directly.
- Add this revision note under `docs/plans/`.
- Commit and push after local review.
