## 关注方向

- To B 产品规划与需求拆解
- 业务流程梳理与角色权限设计
- 需求管理、版本推进与协作跟进
- 产品文档沉淀与信息同步机制

## 工作方式

- 从业务目标出发，明确问题边界与优先级
- 用流程图、需求文档和原型降低沟通成本
- 关注需求闭环：提出、评审、上线、复盘
- 重视可复用的方法、模板和文档体系
