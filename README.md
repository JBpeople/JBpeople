## 仓库概览

### 1) 工业软件 / CAD / 工程数字化

  AI + CADQuery 建模测试，连接产品想法、参数化建模与可运行 Demo。
- **[cad_develop](https://github.com/JBpeople/cad_develop)**  
  CAD 插件相关开发，偏工程侧功能延展与实际落地。

### 2) AI / 自动化工具
- **[CLIProxyAPI](https://github.com/JBpeople/CLIProxyAPI)**
