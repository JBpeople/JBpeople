## About Me

你好，很高兴你来到这里。

我把这个主页当作自己的数字小角落，用来记录平时的学习、项目实践，以及一些和效率工具、自动化、技术折腾有关的内容。相比一份冷冰冰的技术清单，我更希望这里能让人快速了解我在关注什么、正在做什么，也顺手看到一些值得继续展开的项目和记录。

对我来说，GitHub 不只是放代码的地方，也是一块持续积累的空间。每一次尝试、每一个小工具、每一段笔记，最后都会慢慢拼成自己的成长轨迹。

## 最近在做

- 持续整理自己的技术学习路径，把零散知识慢慢沉淀成可复用的经验。
- 折腾一些能提高效率的小工具、小流程，以及更顺手的工作方式。
- 关注实用型技术实践，希望把想法尽快落到真实项目里。
- 记录日常学习中的问题、解法和思考，让输出反过来推动输入。
