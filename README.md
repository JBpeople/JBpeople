## 关注方向

- 需求理解、问题拆解与方案设计
- 流程梳理、角色协作与信息同步
- 工具、脚本与自动化流程落地
- 从想法到 Demo 的快速验证与迭代

## 工作方式

- 从业务目标出发，明确问题边界与优先级
- 用文档、原型、流程图统一认知和推进协作
- 能把抽象需求进一步转成工具、脚本或轻量实现
- 重视闭环：定义问题、推动落地、验证效果、持续优化
